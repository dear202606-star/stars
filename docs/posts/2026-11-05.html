    openbq-org/OpenBB

    75,116收藏
    100分近来仍在更新，说明与许可齐全。

    这是什么

    一个把股票、债券、期权、加密货币等公开和自有数据源统一接入的工具，让同一份数据能同时供 Python 分析、Excel 表格和 AI 助手调用。

    能做什么

    • 它可以把不同来源的金融数据整理成统一格式，用几行 Python 代码取出某只股票的历史价格。
    • 支持把整理好的数据接到 Excel、网页看板或 AI 助手等不同出口，不必为每个出口重做一遍。
    • 覆盖股票、固定收益、衍生品、宏观经济等多个门类，具体数据源清单在文档里列明。

    上手难不难

    需要会写一点 Python 并安装软件包，纯靠鼠标操作走不通。

    谁最适合用

    做量化研究或金融数据分析的人，以及需要把内部数据接到 AI 助手或看板上的数据工程师。它能替他们省掉逐个对接数据源、再为每个前端重复搬运的功夫。

    为什么值得关注

    金融数据来源杂、格式乱，它把这一层统一起来，换数据源时下游代码不用大改。项目已持续维护近六年，七万五千多人收藏，说明有稳定的实际使用基础。公开信息里看不出它自带哪些具体数据源、各源的授权条件如何，用前需要自己核对。

    这是什么

    一个开源的紫微斗数排盘引擎，把传统命理的排盘规则写成程序，供人查盘、研究或做自己的应用。

    能做什么

    • 它可以按出生日期和时辰排出紫微斗数命盘，包含四化（命盘里星曜的四种变化标记）和常见格局判断。
    • 支持查阅古籍原文，并附有倪海厦《天纪》讲课中与紫微斗数相关的原话摘录，标注了集数和时间点。
    • 附带一份公开的解读数据集，按年份打包，可以只下载自己需要的部分。

    上手难不难

    普通使用者直接用在线的排盘页面即可；想自己跑代码或使用数据集，需要会一点命令行和开发环境。

    谁最适合用

    学紫微斗数、想核对排盘结果的人，以及想在自己程序里接入排盘功能的开发者。前者省去手工推盘的麻烦，后者省去从头写算法的功夫。

    排盘规则长期散落在书和口传里，这里把它写成了可查、可复现的代码，讲课原话也逐条标了出处。项目创建半年左右，已有一万六千多人收藏，代码用 MIT 许可，公开信息里看不出背后有什么机构。
