    TauricResearch/TradingAgents

    120,819收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个用多个 AI 角色分工模拟金融交易决策流程的框架，属于量化研究工具，用来观察 AI 在选股和交易判断上能走到哪一步。

    能做什么

    • 它可以让分析师、研究员、交易员等不同角色的 AI 分别处理同一只股票，再汇总成一份决策报告。
    • 支持回测：把每次决策放到之后的收盘价上结算，看这套判断在历史上是否站得住。
    • 报告可以存成单个网页，也可以指定不同模型分别担任不同角色。

    上手难不难

    需要自己装 Python 环境、配置模型接口，并在命令行里运行，不写代码的人基本用不起来。

    谁最适合用

    适合做量化研究或金融 AI 实验的人，替他们省掉从零搭建多角色协作流程和回测框架的时间。普通投资者不适合直接拿来下单。

    为什么值得关注

    它把「多个 AI 分工讨论一只股票」这件事做成了可回测、可复现的流程，而不是只给一段对话。项目两年内持续发布版本，最近的更新修正了模型读到未来财报日期的问题，这类细节说明维护者在认真对待回测的严谨性。公开信息里看不出它的实际收益表现。

    freqtrade/freqtrade

    56,500收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个用 Python 写的加密货币自动交易程序，按事先设定的规则在交易所下单，免费且开源。

    能做什么

    • 它可以连接币安、OKX、Kraken 等多家交易所，按策略自动买卖现货或合约。
    • 支持用历史数据回测策略，先看过去的表现再决定是否投入真钱。
    • 可以通过 Telegram 或网页界面查看和操控运行中的交易。

    上手难不难

    门槛不低：需要自己安装 Python 环境、看懂配置文件，项目方也明确建议使用者具备编程知识。

    谁最适合用

    适合会写代码、想验证自己交易想法的个人；它能替这类人省掉手工盯盘和逐笔下单的重复劳动。

    为什么值得关注

    它把回测、下单和资金管理放在同一套工具里，还提供不接真钱的模拟运行模式，可以先试再动真金。项目说明写得清楚，也一直有更新，五万六千多人收藏。公开信息里看不出它的实际盈利表现。

    ccxt/ccxt

    44,756收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个把上百家加密货币交易所的接口统一成一套写法的程序库，让代码只写一次就能对接不同平台。

    能做什么

    • 它可以连接一百多家加密货币交易所和预测市场，读取行情、下单和查账户。
    • 支持多种编程语言，包括 Python、JavaScript、Go、Java 等。
    • 它能把不同交易所的数据整理成相同格式，方便跨平台比价。

    上手难不难

    需要会写代码，并自己安装运行环境；不写程序的人用不上。

    谁最适合用

    做量化交易或交易机器人的开发者，以及需要批量获取多家交易所行情的数据分析人员。它能替他们省掉逐个平台对接接口的重复工作。

    为什么值得关注

    交易所接口各家不同，改一处往往要动很多地方，这个库把这层差异挡在外面。项目已持续维护九年多，四万四千多人收藏，采用 MIT 许可，代码可自由使用和修改。
