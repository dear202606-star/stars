    TauricResearch/TradingAgents

    120,819收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个用多个 AI 角色模拟交易团队、对股票给出买卖判断的开源框架，属于金融与量化分析工具。

    能做什么

    它可以让分析师、研究员、交易员等不同角色的 AI 分别处理同一只股票，最后汇总成一个决策。

    支持用你自己的 ChatGPT 订阅额度运行，也支持把每次判断保存成报告并回测。

    它能在分析时只使用当时已公开的资料，避免读到决策日之后才发布的财报。

    上手难不难

    需要会装 Python 环境、配置模型接口，并在命令行里运行，不懂技术的普通用户过不了这道门槛。

    谁最适合用

    适合有编程基础、想研究 AI 辅助选股的个人投资者，以及做量化策略原型的研究者。它能替他们省掉自己搭建多角色分析流程的工夫。

    为什么值得关注

    它把「让几个 AI 分头研究再汇总」这件事做成了可复现的流程，并且一直在更新，最近的版本修掉了模型误读未来财报、回测结算口径这类容易出错的地方。十二万多人收藏，说明关注度不低。实际判断准不准，公开信息里看不出来。

    freqtrade/freqtrade

    56,500收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个用 Python 写的开源加密货币交易程序，可以按预设规则自动在交易所下单。

    能做什么

    • 它可以连接币安、OKX、Kraken 等多家交易所，按你写的策略自动买卖。
    • 支持用历史数据回测策略，先在模拟环境里跑，不碰真钱。
    • 可以通过 Telegram 或网页界面查看和控制运行状态。

    上手难不难

    门槛不低，需要自己安装 Python 环境、写策略代码、看懂配置文件，官方也明确建议使用者具备编程基础。

    谁最适合用

    适合会写 Python、想验证自己交易想法的人，替他们省掉手动盯盘和逐笔下单的重复劳动。不懂编程的普通投资者不适合。

    为什么值得关注

    它把回测、模拟运行和实盘控制放在同一套流程里，让人可以先验证再投入真钱，这个顺序本身是稳妥的。项目已持续维护约九年，五万六千多人收藏，说明有长期使用的基础。至于实际收益表现，公开信息里看不出来。

    ccxt/ccxt

    44,756收藏
    94分近来仍在更新，说明与许可齐全。

    这是什么

    一个用代码连接加密货币交易所和预测市场的工具库，把一百多家平台各不相同的接口整理成一套统一的调用方式。

    能做什么

    • 它可以让程序同时读取一百多家交易所的行情数据，包括 Polymarket、Kalshi 这类预测市场。
    • 支持下单、查账户等需要身份验证的操作，也支持实时推送的行情连接。
    • 可以把不同交易所的数据格式统一，方便做跨平台比价。

    上手难不难

    需要会写代码，并自己搭好开发环境；它是个程序库，不是能直接点开用的软件。

    谁最适合用

    写量化策略的开发者，以及需要批量获取多家交易所行情做分析的研究人员。它能替他们省掉逐个平台对接接口的重复工作。

    为什么值得关注

    加密货币交易所接口差异大、变动频繁，这个项目把适配工作集中维护，使用者不必自己追着每家平台改代码。项目采用 MIT 许可，公开仓库有四万四千多人收藏，最近仍有更新。
