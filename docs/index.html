    KKKKhazix/agent-autoloop

    3,079收藏

    这是什么

    一个让命令行 AI 编程助手在后台自动接任务、自己跑完的工具，属于任务调度类软件。

    能做什么

    • 它可以按定时规则或外部事件（如新提交的 Issue）自动把任务交给 Claude Code、Codex 这类命令行 Agent 执行。
    • 支持在遇到删除数据、花钱等需要确认的操作时，通过飞书、钉钉或桌面通知发卡片向你请示，等你回复期间不占进程、不消耗 Token。
    • 支持用一份 JSON 规则文件配置“什么事、交给谁、在哪个目录干”，保存后几秒生效。

    上手难不难

    要装点东西，跟着说明走就行。需要 macOS 或 Linux、Node 24、Git 和 curl，并用一条命令安装；Windows 版目前待定，作者称周末完成兼容性测试。

    谁最适合用

    适合已经在用命令行 AI 编程助手、希望把重复任务（如每日早报、Issue 处理）交给它自动跑的个人开发者。能替他们省掉守在终端前等结果的时间。

    为什么值得关注

    创建 2 天积累 3,079 收藏、581 次复制，标签集中在 ai-agents、automation、claude-code 方向。公开信息里看不出关注度集中的具体原因，但数据说明需求确实存在：此前这类 Agent 大多需要人守着终端，关掉窗口任务就断。

    这是什么

    • 它会给出处置建议并附回滚命令，区分可自动执行、需人工确认和不宜改动的操作。
